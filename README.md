# Coach bass swap

Entraînement aux transitions DJ dans le navigateur : swap des basses guidé par phrase de 32 temps, analyse et replay de chaque transition.

- Pilotable par une Pioneer DDJ-FLX4 (Web MIDI, Chrome ou Edge), ou à la souris.
- Bibliothèque : import de la collection rekordbox (XML), liaison avec le dossier musique, recommandations du morceau suivant (tempo, tonalité Camelot, genre, énergie).
- Démos audio générées par le code (house, techno, afro), ou import de tes propres morceaux : le tempo est détecté sur ton appareil, rien n'est envoyé.

## Utilisation

Ouvre le site, branche la FLX4 en USB (rekordbox fermé), puis clique sur « Configurer ma FLX4 » si un contrôle ne réagit pas.
