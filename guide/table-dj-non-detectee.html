Ma table DJ n'est pas détectée par l'ordinateur : que faire ?

Mis à jour le 27 octobre 2026 · par Nathan, créateur de DJingood

En bref

Vérifie dans l'ordre : ferme les autres logiciels DJ (sur Windows, une table ne parle qu'à un seul logiciel à la fois), puis branche la table directement sur l'ordinateur, avec le câble livré avec, sans hub. Une table tout-en-un, avec un écran, doit être passée en mode ordinateur, et sur Windows certaines tables demandent leur pilote. Sur un site web comme DJingood, il faut en plus Chrome ou Edge, et autoriser l'accès aux appareils MIDI.

Dans l'ordre

Six vérifications.

  1. Ferme les autres logiciels DJ. rekordbox, Serato, djay, VirtualDJ… Sur Windows, une table ne parle qu'à un seul logiciel à la fois : si un autre l'a prise, elle reste invisible pour le suivant, même ouvert en arrière-plan.
  2. Le câble et le port. Branche la table directement sur l'ordinateur, sans hub ni rallonge, avec le câble livré avec : certains câbles USB ne font que charger, sans transporter de données. Essaie aussi un autre port.
  3. Allume-la. Si ta table a une prise de courant ou un interrupteur, vérifie qu'elle est branchée et allumée.
  4. Le mode ordinateur. Une table tout-en-un, avec un écran (XDJ-AZ, XDJ-RX3, XDJ-XZ…), joue aussi sans ordinateur : il faut la passer en mode ordinateur, ou « contrôle par logiciel ». Son manuel dit comment.
  5. Le pilote, sur Windows. Certaines tables demandent d'installer leur pilote, sur la page d'assistance de la marque. La DDJ-FLX4 et la plupart des petites tables n'en ont pas besoin. Dans le Gestionnaire de périphériques de Windows, un point d'exclamation jaune à côté de ta table signale un souci de pilote.
  6. Débranche, rebranche, relance. Débranche la table, rebranche-la, puis relance le logiciel. Vérifie dans ses réglages que ta table est bien choisie. En dernier recours, redémarre l'ordinateur, table branchée.
Sur un site web

Ce qu'il faut en plus dans un navigateur.

  • Chrome ou Edge, sur un ordinateur. Safari ne sait pas parler aux tables DJ, et aucun navigateur d'iPhone ou d'iPad non plus.
  • Autorise l'accès. La première fois, le navigateur demande si le site peut utiliser tes « appareils MIDI » : c'est ta table. Clique sur « Autoriser ».
  • Déjà refusé ? Clique sur l'icône à gauche de l'adresse du site, mets « Appareils MIDI » sur « Autoriser », puis recharge la page.
  • Sur Windows, ferme rekordbox avant d'ouvrir le site : la table ne peut pas parler aux deux en même temps.

DJingood te dit ce qui coince.

Ouvre DJingood dans Chrome : en haut de la page, une pastille donne le nom de ta table dès qu'elle est vue, ou ce qui l'en empêche (« Table non autorisée », « Prends Chrome ou Edge »…). La page « Ma table » te dit quoi vérifier. Une quinzaine de tables de débutant sont reconnues toutes seules ; les autres se règlent pas à pas, en une minute.

Questions fréquentes
Le voyant de ma table s'allume, mais rien ne bouge dans le logiciel ?

La table reçoit du courant, mais le logiciel ne l'écoute pas : un autre logiciel l'a peut-être prise (ferme-le), ou elle n'est pas choisie dans les réglages du logiciel. Une table tout-en-un doit aussi être en mode ordinateur.

Ma table marche dans rekordbox, mais pas sur un site ?

Ferme rekordbox : sur Windows, la table ne peut pas parler aux deux en même temps. Puis ouvre le site dans Chrome ou Edge, et autorise l'accès aux appareils MIDI.

Ça marche sur Mac avec Safari ?

Pour un logiciel comme rekordbox, oui. Pour un site web, non : Safari ne sait pas parler aux tables DJ. Ouvre le site dans Chrome ou Edge, qui marchent aussi sur Mac.

Ça marche sur iPhone ou iPad ?

Pas sur un site web : aucun navigateur d'iPhone ou d'iPad ne parle aux tables DJ. Certaines applications le font, comme rekordbox ou djay, avec une table compatible.
